# Fontes locais

Nunito Sans, Playfair Display, Great Vibes e Rye, nas mesmas versões WOFF2 Latin já usadas no projeto através de next/font/google. Os arquivos foram preservados do build local e agora são carregados por next/font/local, sem downloads de fontes durante o build de produção.

Origem: Google Fonts (https://github.com/google/fonts). As licenças SIL Open Font License de cada família acompanham estes arquivos. O subconjunto Latin inclui os caracteres acentuados utilizados em português.
