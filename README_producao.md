# Produção — Cardápio Dia das Mães

## Escopo
- Projeto base: `Cardapio Dia das Maes`
- Conteúdo protegido: nomes dos pratos, descrições e valores
- Objetivo: adaptar identidade visual para campanha Dia das Mães

## Estrutura
- `01_referencias_agencia/`: referências oficiais da campanha
- `02_assets_visuais/`: texturas, elementos florais, logos e apoio visual
- `03_editaveis/`: fontes e arquivos editáveis de produção
- `04_exports/`: finais em alta
- `05_aprovacao/`: prévias para validação

## Controle de versão
- Trabalhar em incrementos: `v01`, `v02`, `v03`...
- Nunca sobrescrever `final`
- Caso necessário, gerar `final-ajustes`

## Padrão de nomes
- `cardapio-dia-das-maes_v01.ext`
- `cardapio-dia-das-maes_v02.ext`
- `cardapio-dia-das-maes_final.ext`

## Checklist de qualidade
- Conteúdo: ortografia, acentuação e valores
- Visual: contraste, alinhamento e espaçamento
- Marca: logo correto e unidade estética da campanha
